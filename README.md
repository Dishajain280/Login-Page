##React Login & Signup with MongoDB
A simple and secure authentication system built using the React framework for the frontend and MongoDB for the backend. This project includes both Login and Signup pages, with user data stored in a MongoDB database.

#🚀 Features
React frontend with responsive design

Login page for existing users

Signup page with form validation

MongoDB integration for storing user credentials

Password hashing for secure authentication

Session management using JWT tokens

Error handling and user feedback


#🛠️ Tech Stack
Technology	        Purpose
React	        	Frontend framework
Node.js & Express	Backend server
MongoDB	        	Database
JWT		            Authentication tokens
bcrypt	        	Password hashing
